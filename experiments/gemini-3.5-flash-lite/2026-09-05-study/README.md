# Gemini 3.5 Flash Lite study

This directory contains the complete September 5 paper study for LEDGAR, CFPB,
and SpamAssassin. The frozen plan, protocol, amendments, evidence, and manuscript
audit are grouped under one study root.

- `ledgar-valid/` contains the reported LEDGAR collection. `ledgar/` preserves
  the earlier superseded LEDGAR work.
- `cfpb/` contains the reported CFPB collection. Its selection gate rejected the
  candidate, so its reserved final test remained unopened.
- `spamassassin/initial/` preserves development and the original selection work.
- `spamassassin/amendment-01-superseded/` preserves the first amended attempt.
- `spamassassin/amendment-02-final/` contains the reported selection and final
  test evidence.
- `manuscript/` contains the derived calculations, portable evidence inventory,
  provenance notes, review responses, and artifact audit.

Historical command ledgers, logs, plans, outputs, and collection manifests are
preserved as recorded. Some contain the paths that existed when their commands
ran. The portable inventories in `manuscript/` use the current repository paths.
